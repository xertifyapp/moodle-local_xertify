# Contributing

Thank you for helping improve Xertify Certificates for Moodle.

## Development checks

Before submitting changes, please test the plugin in a clean Moodle instance and run Moodle coding-standard checks when available:

- Moodle Code checker
- Moodle PHPDoc checker
- Moodle Plugin CI

## Security

Do not commit real API tokens, customer IDs, template IDs, group IDs, or personal data.

Report security issues privately to the Xertify team instead of opening a public issue.
